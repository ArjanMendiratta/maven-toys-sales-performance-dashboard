# Maven Toys – Sales Performance Dashboard

## Project Overview

This project analyses retail sales performance for Maven Toys using **Microsoft Power BI**. The dashboard provides insights into sales, revenue, profitability, product categories, and store locations.

The objective is to transform raw sales data into an interactive business intelligence dashboard that helps stakeholders understand performance and identify useful business trends.

## Business Objectives

- Analyse overall sales performance.
- Track total orders, revenue, and profit.
- Compare performance across product categories.
- Monitor monthly revenue trends.
- Evaluate sales performance across different store locations.

## Tools & Technologies

- Microsoft Power BI
- Power Query – Data cleaning and transformation
- DAX – Calculated columns and measures
- Data Modelling – Star schema

## Dataset

The project uses four datasets:

| Dataset | Description |
|---|---|
| Sales | Individual sales transactions |
| Products | Product details, costs, and prices |
| Stores | Store information and locations |
| Calendar | Date dimension for time-based analysis |

**Dataset size:** 829,262 sales transactions.

## Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Orders | 829,262 |
| Total Revenue | 14.44M |
| Total Profit | 4.01M |
| Profit Margin | 27.79% |

*Values are rounded.*

## Dashboard Features

- KPI cards displaying total orders, revenue, and profit.
- Monthly revenue trend analysis.
- Sales comparison by product category.
- Interactive store location slicer.
- Dynamic filtering to explore performance across locations.

## Data Preparation & Modelling

The project involved:

1. Cleaning and transforming data using Power Query.
2. Correcting data types and formatting.
3. Creating relationships between the four tables.
4. Building a star-schema data model.
5. Creating calculated columns and DAX measures.
6. Developing interactive dashboard visualisations.
